# Browser Stability & Performance Optimizer

A Chrome extension built to help stabilize Chrome, reduce RAM pressure, and fix common loading issues with fast cleanup actions and browser health visibility.

## Features

- **Quick Optimize** — clears cache, cookies, and site storage for fast browser stabilization.
- **Discard Inactive Tabs** — frees memory by discarding background tabs that are not in use.
- **Browser Health Monitor** — shows active tabs, installed extensions, and recommended actions.
- **Extension Management Panel** — lists installed extensions with enable/disable toggles.
- **Repair Connection** — clears cached browser data that can cause DNS or loading failures.
- **Performance Boost** — runs a combined optimization cycle in one click.

## Installation

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `MyChromeExtension` folder.

## Usage

1. Click the extension icon to open the popup.
2. Use the **Browser Health Monitor** to check active tabs and extension status.
3. Run **Quick Optimize** or **Performance Boost** for one-click cleanup.
4. Use **Discard Inactive Tabs** to reduce memory usage without closing tabs.
5. Use the extension list to enable or disable installed extensions.

## Notes

- The panel may require browser approval for extension management access.
- Some advanced browser metrics are not available via Chrome extension APIs. This tool focuses on fast cleanup and stability actions.
